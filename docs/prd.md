# Product Requirements Document: RM Group Strategies LLC Website

## 1. Overview

RM Group Strategies LLC will build a professional corporate website for a Nevada-based parent company specializing in government contracting, transportation, fleet services, construction, remodeling, logistics, equipment rental, procurement solutions, and business consulting.

The website should present RM Group Strategies LLC as a polished, credible, Fortune 500-style government contractor and diversified business group. The site should be optimized for lead generation, procurement opportunities, subcontracting partnerships, and consultation requests.

## 2. Technology stack

- PHP
- MySQL
- Tailwind CSS
- HTML5
- CSS3
- Custom mail through SMTP
- Namecheap hosting

## 4. Product goals

- Build a professional public website for RM Group Strategies LLC.
- Communicate the company's diversified service portfolio clearly.
- Establish credibility for government, commercial, and private-sector clients.
- Support federal, state, local, and prime-contractor procurement opportunities.
- Capture qualified leads through consultation, contract opportunity, vendor, and subcontractor forms.
- Provide a strong foundation for future bid portal, supplier diversity, and government news features.

## 5. Target audiences

### 5.1 Government procurement officers

Federal, state, local, municipal, and educational-institution buyers evaluating RM Group Strategies LLC for contracting opportunities.

### 5.2 Prime contractors

Prime contractors seeking subcontracting partners for construction, logistics, transportation, fleet support, equipment rental, administrative support, or procurement services.

### 5.3 Commercial and private-sector clients

Businesses and private-sector clients seeking transportation, fleet, construction, remodeling, equipment, or consulting support.

### 5.4 Vendors and subcontractors

Companies interested in partnering with RM Group Strategies LLC or registering as vendors or subcontractors.

## 6. Core user stories

- As a visitor, I want to understand RM Group Strategies LLC's services quickly so that I can determine whether the company is a fit for my needs.
- As a government buyer, I want to review contracting capabilities so that I can evaluate RM Group Strategies LLC for procurement opportunities.
- As a prime contractor, I want to review core competencies and differentiators so that I can assess subcontracting partnership potential.
- As a visitor, I want to request a consultation so that I can speak with the business development team.
- As a procurement contact, I want to submit a contract opportunity inquiry so that RM Group Strategies LLC can follow up.
- As a vendor or subcontractor, I want to register my interest so that RM Group Strategies LLC can evaluate partnership opportunities.
- As the business development team, we want all forms stored in MySQL and sent by custom mail so that no inquiry is lost.

## 10. MVP functional requirements

### 10.1 Responsive public website

- Build mobile-first pages using HTML5 and Tailwind CSS.
- Use CSS3 for custom brand refinements.
- Use the black-and-gold brand palette consistently.
- Support common screen sizes from mobile to desktop.
- Keep the interface fast, readable, and professional.

### 10.2 Contact and lead forms

The site should support these lead forms:

- General contact form
- Request consultation form
- Contract opportunity inquiry form
- Vendor registration form
- Subcontractor registration form
- Capability statement request form

Each form should:

- Validate required fields server-side in PHP.
- Sanitize submitted data before storage and display.
- Store submissions in MySQL.
- Send a custom email notification to the RM Group Strategies LLC team.
- Show a success or error message after submission.
- Store the source page and inquiry type.

### 10.3 Lead handling

Lead submissions should be handled without an admin dashboard in the MVP:

- Store each lead submission in MySQL for backup and reporting.
- Send each submission to the configured business email address through custom SMTP mail.
- Include the inquiry type, source page, and submitted contact details in the notification email.
- Provide a clear confirmation message to visitors after successful submission.
- Do not include an admin dashboard in the MVP.

### 10.4 Content structure

- Keep reusable PHP layout sections for header, footer, navigation, page hero, service cards, calls to action, and form messages.
- Store configurable business settings in MySQL where practical.
- Make future page additions straightforward.

### 10.5 Custom mail

- Send inquiry notifications through SMTP.
- Support configurable sender name, sender email, and recipient email.
- Use email templates for consistent branding.
- Log email delivery attempts for troubleshooting.
- Route government contracting inquiries to `contracts@rmgroupstrategies.com` unless changed by configuration.

## 12. Technical requirements

### 12.1 Backend

- Use PHP 8.2 or the newest stable PHP version supported by the selected Namecheap plan.
- Use MySQL through PDO prepared statements.
- Keep configuration values outside committed source files when possible.
- Structure the app so the public web root exposes only public assets and entry files.

### 12.2 Frontend

- Use semantic HTML5.
- Use Tailwind CSS for responsive layouts and components.
- Use CSS3 for custom styling, transitions, and brand details.
- Use accessible contrast for black, dark gray, gold, and white combinations.
- Avoid unnecessary JavaScript for the MVP.
- Ensure forms are usable on mobile devices.

### 12.3 Hosting

- Deploy to Namecheap hosting.
- Confirm PHP and MySQL versions available on the selected plan before implementation.
- Use Namecheap cPanel or deployment process for database setup, file upload, SSL, and email configuration.
- Keep private files outside public access.

### 12.4 Mail

- Use SMTP-compatible custom mail.
- Store SMTP credentials securely outside public files.
- Support form-submission notifications.
- Consider autoresponder emails after the core contact workflow is stable.

## 13. Security and privacy requirements

- Use prepared statements for all database queries.
- Validate and sanitize all form submissions.
- Escape output to protect against cross-site scripting.
- Use CSRF protection on forms.
- Rate-limit or add spam prevention to public forms.
- Do not commit passwords, API keys, SMTP credentials, or database credentials.
- Use HTTPS in production.
- Provide a privacy policy for visitor-submitted contact information.

## 14. UX requirements

- The site should feel professional, credible, and procurement-ready.
- Primary calls to action should be visible on the home, services, government contracting, capability statement, and contact pages.
- Government contracting content should be easy for procurement officers and prime contractors to scan.
- Contact form errors should be specific and easy to fix.
- The success message should tell the visitor what happens next.
- Page loading should be fast on mobile connections.
- Navigation should remain simple and consistent across pages.

## 15. Success metrics

- Visitors can understand RM Group Strategies LLC's services within the first screen of the home page.
- Government buyers can find contracting capabilities, UEI/SAM readiness, CAGE code information, NAICS codes, and contact details.
- Visitors can submit consultation, contact, contract opportunity, vendor, subcontractor, and capability statement request forms.
- Form submissions are stored in MySQL.

- The website can be deployed successfully to Namecheap hosting.
